Context is the latest native estimate, not lifetime usage; ~ marks an estimate. Hover for token counts, source and reading time. Compactions counts completed events observed in available session records, not a guaranteed lifetime total. Unknown does not mean zero.

Forums lists Pitput boards from launch settings or verified enrollment at launch (hover each board). It does not verify recent communication, current membership, or delivery readiness. Search includes all boards, including collapsed ones. Unknown means older or recovered observations have no board evidence; None configured means Pitput was not configured for that launch. No private DM information is shown.

How to read this table

Running means HRX observed the process. It does not mean the model is generating. History only is a saved session with no live tracking.

Last event determines row order: Claude reports messages, turns and tools; other harnesses currently report launch/session start. Last seen is the latest process observation or event, not the latest message.

Credentials shows broker profile and account metadata recorded at launch. Expand the profile for host, scopes and expiry. This does not verify current access. No tokens or message content are displayed.

Proxmox rows show the last controller stage, its timestamp, and the container ID when known. They do not continuously poll worker health. A failed readiness check does not mean the worker stopped. Use hrx remote inspect --name NAME and hrx remote logs --name NAME to investigate.

Each row is one run. Host and session distinguish repeated names. Add collectors to pool hosts; local use needs no hub.
